# Udemy Certificates

This directory contains certificates earned from Udemy courses.

## Naming Convention
Please follow this naming convention for certificate files:
`YYYY-MM-DD_Course-Name_Certificate.pdf`

Example: `2024-02-10_Complete-Python-Bootcamp_Certificate.pdf`

## Organization
- Group certificates by technology/skill area if you have many
- Consider creating subdirectories for different domains:
  - `programming/` - Programming language courses
  - `web-development/` - Web development courses  
  - `data-science/` - Data science and analytics courses
  - `business/` - Business and entrepreneurship courses

## Certificate Information
For each certificate, consider documenting:
- Course name
- Instructor name
- Completion date
- Course duration/hours
- Rating given to the course
- Key projects or exercises completed
