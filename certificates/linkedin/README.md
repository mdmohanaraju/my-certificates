# LinkedIn Learning Certificates

This directory contains certificates earned from LinkedIn Learning courses.

## Naming Convention
Please follow this naming convention for certificate files:
`YYYY-MM-DD_Course-Name_Certificate.pdf`

Example: `2024-01-15_Data-Science-Foundations_Certificate.pdf`

## Organization
- Group related certificates by topic/skill area if you have many
- Consider creating subdirectories for different skill tracks (e.g., data-science, web-development, project-management)

## Certificate Information
For each certificate, consider adding:
- Course completion date
- Course duration
- Key skills learned
- Instructor name
