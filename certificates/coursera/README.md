# Coursera Certificates

This directory contains certificates earned from Coursera courses and specializations.

## Naming Convention
Please follow this naming convention for certificate files:
`YYYY-MM-DD_Course-or-Specialization-Name_Certificate.pdf`

Example: `2024-03-20_Machine-Learning-Specialization_Certificate.pdf`

## Organization
- Separate individual course certificates from specialization certificates
- Consider creating subdirectories for:
  - `courses/` - Individual course certificates
  - `specializations/` - Multi-course specialization certificates
  - `professional-certificates/` - Professional certificate programs

## Certificate Information
For each certificate, consider documenting:
- Course/Specialization name
- Institution (e.g., Stanford, Google, IBM)
- Completion date
- Course duration
- Grade achieved (if applicable)
- Key projects completed
