# Other Learning Platform Certificates

This directory contains certificates earned from other learning platforms and sources.

## Supported Platforms
- edX
- Pluralsight
- Khan Academy
- FreeCodeCamp
- Codecademy
- AWS Training
- Google Cloud Training
- Microsoft Learn
- Other professional training providers

## Naming Convention
Please follow this naming convention for certificate files:
`YYYY-MM-DD_Platform_Course-Name_Certificate.pdf`

Example: `2024-04-05_edX_Introduction-to-Computer-Science_Certificate.pdf`

## Organization
Consider creating subdirectories by platform if you have certificates from multiple sources:
- `edx/`
- `pluralsight/`
- `aws/`
- `google-cloud/`
- `microsoft/`
- `freecodecamp/`
- etc.

## Certificate Information
For each certificate, consider documenting:
- Platform name
- Course/Program name
- Completion date
- Duration
- Certificate type (completion, verified, professional)
- Skills acquired
